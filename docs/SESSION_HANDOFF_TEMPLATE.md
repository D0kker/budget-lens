# Plantilla de cierre de sesión

Usa esta estructura al actualizar `PROJECT_CONTEXT.md` después de trabajo relevante:

```md
Última actualización: YYYY-MM-DD

## Qué quedó funcionando
- Resultado observable y ubicación del código.

## Decisiones tomadas
- Decisión y motivo; si es duradera, agregarla también a `DECISIONS.md`.

## Validación realizada
- Comandos y resultados relevantes.

## Próximo paso recomendado
- Una acción concreta.

## Preguntas o bloqueos
- Información que debe proporcionar el usuario o dependencia externa pendiente.
```

No incluyas secretos, transcripciones extensas, hipótesis presentadas como hechos ni detalles que puedan reconstruirse fácilmente leyendo el código.
